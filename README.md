# Nutork configurator (Nortek Hendriks)

Standalone product configurator for the Nutork range (valve actuators and accessories), prepared by Nortek Hendriks. Single self-contained HTML file: open `index.html` in a browser.

Online: https://nh-techsolutions.github.io/nh-configurator-nutork/

Snapshot of 17 October 2026. Preview, not an official Nutork tool. Technical data comes from the manufacturer's public documents; verify before ordering. Documents link to the manufacturer's official website.

Part of the Nortek Hendriks 2026 website preview: https://nh-techsolutions.github.io/nh-website-2026/configurators/nutork/
